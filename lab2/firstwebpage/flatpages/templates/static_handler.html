Учет внутриофисных расходов

Информационная система предназначена для учета покупок, совершаемых сотрудниками частной фирмы для нужд организации.

Справочная информация:

  • Сотрудники фирмы;
  • Отделы организации;
  • Виды внутриофисных расходов;
  • Месячные нормативы расходов.

Учет покупок:

  1. Выбор сотрудника;
  2. Указание отдела;
  3. Выбор вида расхода;
  4. Указание даты и суммы покупки;
  5. Регистрация товарного чека.
